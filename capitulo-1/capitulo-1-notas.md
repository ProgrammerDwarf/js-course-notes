



# Notas del capítulo 1

En este capítulo se realizo una introducción a cómo ejecutar código javascript desde la consola del navegador y también desde un editor de código, en este caso VScode fue el escogido para seguir este curso.

En ambos casos pudimos desplegar un mensaje por medio de la función "alert", el cual acepta una cadena de texto y la muestra en un modal una vez la persona ingresa el comando.

El ejercicio que se hizo desde el navegador fue este:

1. Abrir el navegador, en mi caso Mozilla Firefox
2. Ir a la pesataña "console"
3. Ingresar el siguiente comando.

```javascript
alert('Hello from the console')
```

El código que se uso para desplegar el modal desde el editor de código involucró crear un archivo, index.html e ingresar las etiquetas que en ese archivo están. Para que el lenguaje de marcado sepa que estaremos ingresando código JS debemos escribir la función alert dentro de la etiqueta script.
